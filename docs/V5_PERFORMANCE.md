## 🧊 模型加载延迟

> 衡量预加载机制对抢座时序的影响。

| 阶段 | 延迟（CPU） | 说明 |
|------|------------|------|
| ONNX 模型读盘 | ~0.5s | 4 个 ONNX 文件，共 ~210MB |
| onnxruntime 初始化 | ~1-2s | session 创建 + opcache 编译 |
| 首次 YOLO 推理 | ~0.3-0.5s | warmup |
| 首次 Siamese 推理 | ~0.5-1s | warmup |
| **冷启动总延迟** | **~3-5s** | 不预加载场景 |
| **预加载后单次** | **< 1s** | 第二次起 |

### 预加载收益

| 场景 | 06:30 第一次验证码 |
|------|-------------------|
| 不预加载（v5 关闭预加载假设） | 等模型加载 3-5s → 错过提交窗口 |
| **预加载（v5 默认）** | 立即解析 < 1s → 整点零延迟提交 |

## 🧵 多账户并发

> v5 默认 `MAX_ACCOUNTS = 2`。

| 并发数 | 浏览器实例 | 内存峰值 | 推理冲突 | 建议设备 |
|--------|-----------|---------|---------|---------|
| 1 账号 | 1 | ~800MB | 无 | 4GB RAM |
| **2 账号（默认）** | 2 | ~1.5GB | 通过 `_CAPTCHA_SOLVER_LOCK` 串行 | 8GB RAM |
| 3 账号（需手动改 config） | 3 | ~2.3GB | 同上 | 16GB RAM |

### 多账号启动错开

```
06:29:30   账号 1 prep_at（slot 0 × 8 = 0s 偏移）
06:29:38   账号 2 prep_at（slot 1 × 8 = 8s 偏移）
06:29:46   账号 3 prep_at（slot 2 × 8 = 16s 偏移，需扩 MAX_ACCOUNTS）
...
06:29:54   所有账号统一 seat_lock_at
06:30:00   所有账号统一 fire_at
```

源码：`main.py:670` `prep_at += timedelta(seconds=slot_index * 8)`

## ⏱️ 时序精度

> 衡量 `wait_until()` 在 fire_at 触发的实际偏移。

| 等待时长 | 实际抖动 | 测量方式 |
|---------|---------|---------|
| 30 秒以上 | 心跳 1800s | 每 30 分钟一条 INFO 日志 |
| 5–30 秒 | < 200ms | 分段 sleep 0.2s 间隔 |
| 0.5–5 秒 | < 50ms | sleep 0.05s 间隔 |
| 0.02–0.5 秒 | < 10ms | sleep 0.01s 间隔 |
| < 20ms | < 5ms（忙等） | 不 sleep，CPU 忙等 |

> 关键设计：最后 20ms 进入忙等以提高精度，但只持续极短时间，整体 CPU 占用可忽略。
> 源码：`main.py:wait_until()`

## 🔬 v3 vs v5 总对比

| 维度 | v3.0.0 | **v5.0.0** | 改进幅度 |
|------|--------|-----------|---------|
| **GUI 启动时间** | 1-2s（CustomTkinter） | 1-2s（PySide6） | 持平 |
| **首次验证码解析** | 7.21s（API） / 0.51s（本地） | < 1s（预加载后） | API 路径 ~7x 提升 |
| **单次识别准确率** | 100% / 61.2% | 83.48%（Click1） | 自研模型 vs 商业 API trade-off |
| **联网依赖** | 强（API） / 无（本地） | 无 | 完全离线 |
| **单次成本** | 0.016 元 / 0 | **0** | 100% 降本 |
| **exe 包大小** | ~150MB | ~360MB | +210MB 模型权重 |
| **内存峰值（双账号）** | ~1.2GB | ~1.5GB | +0.3GB（ONNX 推理上下文） |
| **支持自习室数** | 20 | **21** | +智慧空间 281 座位 |
| **配置字段数** | 16（含 FORCE_API_ALWAYS） | 15（移除 API 字段，+MAX_ACCOUNTS） | 精简 |

## 🧪 怎么参与测试 / 上报数据

1. 跑一次真实抢座（06:30 高峰最佳）
2. 复制 `logs/sessions/<时间戳>_<学号>/` 整个文件夹
3. 删除其中的 `session.log` / `抢座顺序.txt` 里所有学号密码（隐私）
4. 提 [Issue](https://github.com/XUNRANA/LNU-LibSeat-Automation/issues) 附上文件夹 zip + 你想补充的数据点

我们会聚合用户实测数据更新本文档。
